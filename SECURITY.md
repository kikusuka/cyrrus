# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |

cyrrus is in early active development. Only the latest published version on PyPI receives security attention right now.

## Reporting a Vulnerability

If you find a security issue in cyrrus, please **do not open a public GitHub issue**. Instead:

- Open a [private security advisory](https://github.com/kikusuka/cyrrus/security/advisories/new) on GitHub, or
- Reach out directly on Discord (see README) and flag it as sensitive

You can expect an initial response within a few days. cyrrus is maintained by a solo developer, so timelines are best-effort, not SLA-backed — but every report gets read and taken seriously.

If the report is confirmed, a fix will be prioritized and credited to you (unless you'd prefer to stay anonymous) once it ships.
